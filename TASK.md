# Assignment Scope

Build a complete local FieldLedger submission for the SuperDocs engineering task:

- Process a cited construction document pile into reviewable artifacts.
- Provide the assigned offline-capable phone approval client.
- Provide the selected Word offline instruction queue add-in.
- Expose REST and MCP through the same authority boundary.
- Include reproducible tests, measurements, diagrams, written answers, and a three-to-five-minute demo video.
- Keep the project local: create a new Git repository, add no remote, make no external handoff, and produce a ZIP only after one consolidated review.

Source requirements and their packaged proof are indexed in the [requirement matrix](docs/submission/requirement-matrix.md).
